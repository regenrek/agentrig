```bash
agentrig add go
```

## What's included

- `skills/go/SKILL.md`
- `skills/go/go-check.sh`

## Requirements

- Installs to `{{skillsDir}}` (default `.codex/skills`).

## Usage

Run the Go check workflow and apply recommendations in your repo.
