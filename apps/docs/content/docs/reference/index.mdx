# Reference

This section includes the schemas and data formats used by agentrig.

- Plugin schema (`https://agentrig.ai/schema/plugin.v1.json`) - Open Plugins 1.0.0 conformant with AgentRig-specific fields under `x-agentrig`
- Registry schema (`https://agentrig.ai/schema/registry.json`)
- Plugin history schema (`https://agentrig.ai/schema/plugin-history.json`)
- Source artifact schema (`https://agentrig.ai/schema/agentrig-source.json`)
- Lock artifact schema (`https://agentrig.ai/schema/agentrig-lock.json`)
- Review artifact schema (`https://agentrig.ai/schema/agentrig-review.json`)
- Advisories schema (`https://agentrig.ai/schema/advisories.json`)
- Directory schema (`https://agentrig.ai/schema/directory.json`) - discovery metadata only; identity fields there do not imply install trust
- Config schema (`https://agentrig.ai/schema/config.json`)
- Manifest format (`.agentrig/manifest.json`)
- Placeholder rules
