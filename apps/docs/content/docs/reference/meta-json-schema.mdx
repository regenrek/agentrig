# Plugin schema

The plugin schema is served at:

```
https://agentrig.ai/schema/plugin.json
```

It validates:

- `name`, `title`, `description`, `version`
- `files[]` entries with `path`, `target`, optional `mode` + `sha256`
- optional `author`, `license`, `tags`, `rigDependencies`

Use `$schema` in your `.plugin/plugin.json` for editor hints:

```json
{ "$schema": "https://agentrig.ai/schema/plugin.json" }
```
