# Registry schema

The registry schema is served at:

```
https://agentrig.ai/schema/registry.json
```

Required fields:

- `contract_version`
- `registry_alias`
- `source_repository`
- `generated_at`
- `signature`
- `items[]`

Each item defines:

- `plugin`
- `latest_version`
- `history`
- `trust_tier`
- `installability`

The registry index links to per-plugin history manifests, which in turn link to version artifacts such as `AGENTRIG_SOURCE.json`, `AGENTRIG_LOCK.json`, and `AGENTRIG_REVIEW.json`.
