# Pack structure

Packs are flexible; the required files are `meta.json` and `README.md`.
The rest of the tree can include any files you want installed.

## Common layout

```
pack-name/
  meta.json
  skills/
    <skill-name>/
      SKILL.md
      scripts/
  scripts/
  agents/
  commands/
  hooks/
    hooks.json
  .mcp.json
  .lsp.json
```

## Notes

- **skills/** maps to `{{skillsDir}}` by default during install.
- **scripts/** and other folders install exactly where `meta.json` targets specify.
- **hooks/**, **agents/**, **commands/** are bundled into plugin exports when the target integration supports them.
- **.mcp.json** is bundled into plugin exports that support MCP servers.
- **.lsp.json** is bundled into plugin exports that support LSP configuration.

Use `agentrig pack create` to scan a directory and generate a matching `meta.json`.
