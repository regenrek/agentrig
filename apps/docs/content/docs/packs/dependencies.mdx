# Dependencies

Packs can declare other packs they depend on using `rigDependencies`.
The installer resolves and installs dependencies before the pack itself.

```json
{
  "name": "core-committer",
  "rigDependencies": ["security-check"]
}
```

## How it works

- Dependencies can be pack names, namespaced packs (`@team/pack`), or direct URLs.
- The CLI uses the same resolution rules as `agentrig add`.
- Dependencies are only installed once per install run.

Use dependencies for shared foundations like linters, security checks, or base prompts.
