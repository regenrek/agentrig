# Dependencies

Packs can declare other packs they depend on using `rigDependencies`.
Plugin installs resolve and install dependencies before the requested pack.

```json
{
  "name": "core-committer",
  "rigDependencies": ["security-check"]
}
```

## How it works

- Dependencies can be official pack names, `registryAlias/pack` specs, or direct URLs.
- Dependencies inherit the same registry when a pack is installed from a configured registry.
- Direct URL or local-file installs must use explicit dependency specs for any dependent packs outside that source.
- Dependencies are only installed once per install run.

Use dependencies for shared foundations like linters, security checks, or base prompts.
