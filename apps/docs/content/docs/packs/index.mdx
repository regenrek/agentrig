# Packs overview

A pack is a portable unit of workflow logic. Each pack ships files plus a `meta.json` file that describes how to install them.

<Files>

      <File name="lint.sh" />
    </Folder>
  </Folder>
</Files>

## What the CLI does

- Reads the pack `meta.json`.
- Validates target paths and hashes.
- Writes files to the target directory (`{{skillsDir}}` by default).
- Records the install in `.agentrig/manifest.json`.
