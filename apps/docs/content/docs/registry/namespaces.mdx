# Namespaces

Self-hosted registries can be referenced by namespace, for example:

```
@acme/tauri-rust
```

To resolve a namespaced pack (`@namespace/pack`), agentrig uses your `namespacedRegistries` config.
The public directory index is for discovery and trust signals; it does not configure your machine automatically.

## Configure a namespace

In `agentrig.config.json`:

```json
{
  "namespacedRegistries": {
    "@acme": "https://example.com/registry/{name}.json"
  }
}
```

The `{name}` placeholder is replaced with the pack name.

You can also provide headers or query params:

```json
{
  "namespacedRegistries": {
    "@acme": {
      "url": "https://example.com/registry/{name}.json",
      "headers": { "Authorization": "Bearer ${TOKEN}" },
      "params": { "team": "infra" }
    }
  }
}
```

## Directory entries

The public directory index is an array of entries with this shape:

```json
{
  "name": "@acme",
  "homepage": "https://example.com",
  "url": "https://example.com/registry/{name}.json",
  "description": "Internal automation packs",
  "verified": true,
  "tags": ["internal", "workflow"]
}
```

Submit your namespace to the directory to appear in `/directory/index.json`.
