# Trust tiers

Agentrig assigns each pack source a trust tier to protect your filesystem.

| Tier | Source | Behavior |
| --- | --- | --- |
| `official` | `https://agentrig.ai/registry` | Always trusted. |
| `listed` | Namespaces in the directory index | Trusted, no prompt. |
| `unlisted` | Direct URLs or unknown registries | Requires confirmation (`--yes`). |

## How trust is determined (current CLI behavior)

- **Official**: if the pack is resolved from the official registry (`https://agentrig.ai/registry`).
- **Listed**:
  - Installing `@namespace/pack` **and** `namespacedRegistries` includes `@namespace`, **and** the directory entry for `@namespace` is marked `verified: true`.
  - Installing a direct meta URL that matches the base URL of a verified directory entry.
- **Unlisted**: everything else (including plain pack names from non-official registries).

If the directory index cannot be fetched, sources fall back to `unlisted`.

## Confirmation for unlisted sources

If a pack comes from an unlisted source, the CLI shows the install plan and exits:

```bash
agentrig add https://example.com/some-pack.json
# Re-run with:
agentrig add https://example.com/some-pack.json --yes
```

## Path validation

Regardless of trust tier, all targets are validated against a safe prefix list to prevent path traversal.
