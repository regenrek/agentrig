# Trust tiers

Agentrig assigns each plugin source a trust tier before plugin installation.

| Tier | Source | Behavior |
| --- | --- | --- |
| `official` | `https://agentrig.ai/registry` | Always trusted. |
| `listed` | Explicitly configured registries in your config | Trusted, no prompt. |
| `unlisted` | Direct URLs, local files, or unknown registries | Requires confirmation (`--yes`). |

## How trust is determined

- **Official**: the plugin resolves from the official registry seeded by `agentrig init`.
- **Listed**: the plugin resolves from a registry you explicitly added with `agentrig registry add`.
- **Unlisted**: the plugin resolves from a direct URL, local file, or some other source outside your configured registries.

## Confirmation for unlisted sources

If a plugin comes from an unlisted source, AgentRig refuses to continue until you confirm it:

```bash
agentrig plugin install codex https://example.com/some-plugin.json
# Re-run with:
agentrig plugin install codex https://example.com/some-plugin.json --yes
```

## Path validation

Regardless of trust tier, plugin metadata is still validated against AgentRig's allowed target prefixes to block unsafe or non-standardized install targets.
