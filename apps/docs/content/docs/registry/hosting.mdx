# Hosting a registry

A registry is a static folder that contains:

```
registry.json
<plugin>.json
plugins/<plugin>/**
```

## Minimum requirements

- `registry.json` at the registry root.
- One JSON file per plugin (`<plugin>.json`).
- All files referenced by `.plugin/plugin.json` at the paths specified by each `files[].path` entry.

## Example

```
https://example.com/registry/
  registry.json
  core-committer.json
  plugins/
    core-committer/
      skills/committer/SKILL.md
```

## Test locally

Start any static server at the registry root and add it as a registry:

```bash
agentrig registry add example https://example.com/registry
agentrig plugin install codex example/core-committer
```
