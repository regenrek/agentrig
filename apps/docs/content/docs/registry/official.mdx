# Official registry

The official registry is served from:

```
https://agentrig.ai/registry
```

It is treated as **trust tier: official** in the CLI.

## What it contains

- `registry.json` - the plugin index
- `manifests/<plugin>.json` - plugin version history and pointers
- `plugins/<plugin>/<version>/` - the published plugin payloads

## Canonical source

The canonical source of truth for the official registry is the [`agentrig-registry`](https://github.com/agentrig/agentrig-registry) GitHub repository.

For local development, run `pnpm build:registry` to generate a local snapshot from the canonical source. The output is gitignored and never committed.

## CLI behavior

The CLI automatically trusts the official registry and does not require confirmation prompts.
