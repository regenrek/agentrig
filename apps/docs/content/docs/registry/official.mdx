# Official registry

The official public registry is served from:

```
https://agentrig.ai/registry
```

It is the canonical public install source for AgentRig and is treated as **trust tier: `official`**.

## What makes it installable

Only static, git-mirrorable, signed registries are publicly installable.

The official registry is the reference implementation of that contract.

The public directory is not an install source.
An entry may be visible in the directory before it is installable, but installability still comes only from merged registry state.

## Canonical source

The canonical source of truth for the official registry is the [`agentrig-registry`](https://github.com/agentrig/agentrig-registry) GitHub repository.

## Canonical layout

The canonical registry layout is:

- `registry.json`
- `plugins/<namespace>/<plugin>/plugin.json`
- `plugins/<namespace>/<plugin>/versions/<version>/`
- `plugins/<namespace>/<plugin>/versions/<version>/.plugin/plugin.json`
- `plugins/<namespace>/<plugin>/versions/<version>/AGENTRIG_SOURCE.json`
- `plugins/<namespace>/<plugin>/versions/<version>/AGENTRIG_LOCK.json`
- `plugins/<namespace>/<plugin>/versions/<version>/AGENTRIG_REVIEW.json`
- `advisories.json`

Canonical plugin ids use:

```text
namespace.plugin
```

Canonical install refs use:

```text
<registryAlias>/<namespace.plugin>@<version>
```

Example:

```text
agentrig/agentrig.typescript@0.1.0
```

## CLI behavior

The CLI should treat official registry entries as installable without falling back to ad hoc URL, ZIP, or author-repo installs.
