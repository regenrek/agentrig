# Run a team registry

Teams can host their own registry and publish private plugins without changing the core consumer flow.

## 1. Host the registry

Publish the `registry.json`, `<plugin>.json`, and `plugins/<plugin>/**` files on a static host.

## 2. Add the registry explicitly

```bash
agentrig registry add acme https://acme.example/registry
```

## 3. Browse and install plugins

```bash
agentrig list --available --registry acme
agentrig plugin install codex acme/infra-safety
```

## 4. (Optional) Get listed

Submit your registry to the public directory if you want discovery on agentrig.ai.
