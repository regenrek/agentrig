# Run a team registry

Teams can host their own registry and publish private plugins without changing the core consumer flow.

## 1. Host the registry

Publish a static signed registry that follows the canonical contract:

- `registry.json`
- `plugins/<namespace>/<plugin>/plugin.json`
- `plugins/<namespace>/<plugin>/versions/<version>/...`
- `advisories.json`

## 2. Add the registry explicitly

```bash
agentrig registry add acme https://acme.example/registry
```

## 3. Browse and install plugins

```bash
agentrig list --available --registry acme
agentrig plugin install codex acme/acme.infra-safety@1.4.2
```

## 4. (Optional) Get listed

Submit your registry to the public directory if you want discovery on agentrig.ai.

Directory listing remains discovery-only and does not upgrade install trust on its own.
