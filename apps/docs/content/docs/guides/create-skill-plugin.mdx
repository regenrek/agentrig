# Create a skill plugin

This guide walks through creating a new plugin for a reusable skill.

## 1. Scaffold

```bash
agentrig plugin init my-skill-plugin
```

## 2. Add skill files

Place your skill under `skills/<skill-name>/SKILL.md` and any supporting scripts alongside it.

## 3. Generate .plugin/plugin.json

```bash
agentrig plugin create . --out .plugin/plugin.json
```

## 4. Test locally

Install your plugin from the local `.plugin/plugin.json` as a provider plugin:

```bash
agentrig plugin install codex ./my-skill-plugin/.plugin/plugin.json --yes
```

## 5. Publish

Publish to your own registry or contribute to the official registry. See [Publishing plugins](/plugins/publishing).

<Callout title="Contributing to the official registry?">
See [Contribute](/contribute/official-registry) for the repo workflow and `pnpm registry:build`.
</Callout>
