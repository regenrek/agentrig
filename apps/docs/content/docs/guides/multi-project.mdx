# Multi-project setup

Use global config for shared rigs and registries, and project config for overrides.

## Global config

```bash
agentrig init --global
```

Add shared registries and rigs in `~/.agentrig/config.json`.

## Project config

In each repo, write a minimal config:

```bash
agentrig init --minimal --defaultRig core
```

This keeps per-repo config small while reusing your global setup.
