# Project config

Project config lives at:

```
<repo>/agentrig.config.json
```

Use it for repo-specific registries and advanced rig definitions.

```json
{
  "registries": [{ "name": "agentrig", "url": "https://agentrig.ai/registry" }]
}
```

You can also add third-party registries at the project level:

```json
{
  "registries": [
    { "name": "agentrig", "url": "https://agentrig.ai/registry" },
    { "name": "georg", "url": "https://georg.dev/agentrig" }
  ]
}
```

Project config overrides global config when keys overlap.
