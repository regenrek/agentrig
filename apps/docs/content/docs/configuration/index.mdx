# Configuration overview

Agentrig reads configuration from two locations:

- **Global**: `~/.agentrig/config.json`
- **Project**: `<repo>/agentrig.config.json`

The CLI merges them with project settings taking precedence.
Use `agentrig init` or edit the files directly.
