# Config schema

```json
{
  "$schema": "https://agentrig.ai/schema/config.json",
  "registries": [{ "name": "official", "url": "https://agentrig.ai/registry" }]
}
```

## Fields

| Field | Description |
| --- | --- |
| `registries` | Configured registries as `name + base URL`. |
| `rigs` | Optional advanced rig definitions. |
| `defaultRig` | Optional default rig name. |
| `$schema` | Optional JSON schema hint. |
