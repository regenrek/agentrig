# Rigs overview

A rig is a named set of plugins that you can apply to any project.
Rigs live in `agentrig.config.json` (project) or `~/.agentrig/config.json` (global).

## Why rigs

- Keep team baselines consistent.
- Apply multiple plugins in one command.
- Extend base rigs with project-specific plugins.
