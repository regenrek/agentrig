# Defining rigs

Rigs are stored under the `rigs` key in your config file.

```json
{
  "rigs": {
    "core": {
      "plugins": [
        "agentrig/agentrig.core-committer@0.1.0",
        "agentrig/agentrig.security-check@0.1.0"
      ]
    },
    "tauri-agentic": {
      "extends": ["core"],
      "plugins": ["agentrig/community.typescript@0.1.0"]
    }
  },
  "defaultRig": "core"
}
```

## Fields

- `plugins` - list of canonical install refs to install.
- `extends` - list of parent rigs to merge in order.
- `defaultRig` - used when you run `agentrig rig apply` without a name.
