# Applying rigs

Use `agentrig rig apply` to install all plugins for a rig.

```bash
agentrig rig apply codex core
```

## Flags

- `--scope <auto|personal|workspace>` - select the provider install scope.
- `--force` - overwrite an existing AgentRig-managed provider plugin when safe.
- `--prune` - remove plugins not in the rig (default: true).
- `--dry-run` - print the provider-native install and prune plan without writing.

The provider is required. The rig name is optional only when `defaultRig` is
configured. The CLI resolves all plugin graphs, emits one provider-native
install plan, and updates the applicable v4 install ledger.
