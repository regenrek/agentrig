# Extending rigs

Rigs can extend other rigs using the `extends` array.
The CLI resolves plugins in order and de-duplicates while preserving order.

Example:

```json
{
  "rigs": {
    "core": {
      "plugins": [
        "agentrig/agentrig.core-committer",
        "agentrig/agentrig.security-check"
      ]
    },
    "website": { "extends": ["core"], "plugins": ["agentrig/community.typescript"] }
  }
}
```

When you apply `website`, agentrig installs:

1. `agentrig/agentrig.core-committer`
2. `agentrig/agentrig.security-check`
3. `agentrig/community.typescript`

This keeps shared foundations in one place.
