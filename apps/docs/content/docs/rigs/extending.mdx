# Extending rigs

Rigs can extend other rigs using the `extends` array.
The CLI resolves packs in order and de-duplicates while preserving order.

Example:

```json
{
  "rigs": {
    "core": { "packs": ["core-committer", "security-check"] },
    "website": { "extends": ["core"], "packs": ["typescript"] }
  }
}
```

When you apply `website`, agentrig installs:

1. `core-committer`
2. `security-check`
3. `typescript`

This keeps shared foundations in one place.
