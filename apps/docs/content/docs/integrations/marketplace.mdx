# Marketplace exports

Use `agentrig pack plugin export` to export packs as individual plugins for Claude, Codex, Cursor, or all three at once.

```bash
agentrig pack plugin export --agent all --packsDir registry/packs --out dist/plugins
```

This generates:

```text
dist/plugins/
  claude/
  codex/
  cursor/
```

## Optional config file

Create `agentrig.plugins.json` to customize output:

```json
{
  "pluginPrefix": "agentrig-",
  "owner": { "name": "Agentrig", "email": "team@agentrig.ai" },
  "providers": {
    "claude": {
      "marketplaceName": "agentrig-community"
    },
    "codex": {
      "marketplaceName": "agentrig-local",
      "displayName": "Agentrig Local"
    },
    "cursor": {
      "marketplaceName": "agentrig-marketplace"
    }
  },
}
```

The exporter reads this file automatically when present. For backward compatibility, `agentrig.marketplace.json` is still supported for Claude-only settings.
