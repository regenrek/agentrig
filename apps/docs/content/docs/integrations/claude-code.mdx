# Claude Code integration

Agentrig can export packs as Claude Code plugins so they are installable via the Claude marketplace UI.

## Build the marketplace

```bash
agentrig pack plugin export --agent claude --packsDir registry/packs --out dist/claude-marketplace
```

This generates:

```
dist/claude-marketplace/
  .claude-plugin/marketplace.json
  plugins/
    agentrig-<pack>/
      .claude-plugin/plugin.json
      skills/...
      commands/...
      agents/...
```

## Install in Claude Code

```bash
agentrig pack plugin install --agent claude
```

Agentrig uses the native `claude plugin marketplace add` and `claude plugin install` commands under the hood.

If you prefer the old export-only command, `agentrig pack claude-marketplace` still works as a compatibility alias.

## Using commands and skills

Claude plugins expose commands and skills under the plugin name, for example:

```text
/agentrig-core-committer:committer
```
