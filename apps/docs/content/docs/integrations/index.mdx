# Integrations

AgentRig can take a resolved pack and install it as a native plugin for:

- `Claude Code`
- `Codex`
- `Cursor`

## Consumer flow

```bash
agentrig plugin install <provider> <pack-spec>
agentrig plugin uninstall <provider> <pack-spec>
```

`<pack-spec>` can be:

- an official pack name such as `core-committer`
- a third-party pack from an added registry such as `georg/ts-master-pack`
- a direct `meta.json` URL
- a local `meta.json` path

## Author flow

If you are publishing or testing local packs, export provider-native marketplaces from pack directories:

```bash
agentrig pack plugin export --agent <provider|all> --packsDir registry/packs
```
