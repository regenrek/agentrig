# Integrations

AgentRig can take a resolved plugin and install it as a native plugin for:

- `Claude Code`
- `Codex`
- `Cursor`

## Consumer flow

```bash
agentrig plugin install <provider> <plugin-spec>
agentrig plugin uninstall <provider> <plugin-spec>
```

`<plugin-spec>` can be:

- an official plugin name such as `core-committer`
- a third-party plugin from an added registry such as `georg/ts-master-plugin`
- a direct `.plugin/plugin.json` URL
- a local `.plugin/plugin.json` path

## Author flow

If you are publishing or testing local plugins, export provider-native marketplaces from plugin directories:

```bash
agentrig plugin export --agent <provider|all> --pluginsDir registry/plugins
```
