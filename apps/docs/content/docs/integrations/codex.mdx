# Codex integration

Install a resolved plugin into Codex:

```bash
agentrig plugin install codex agentrig/agentrig.core-committer --scope personal
```

`--scope auto` is the default selector.
For Codex plugins, `auto` resolves to `personal`.
Refs resolve to the latest installable registry version by default; add
`@<version>` only for an explicit reproducibility or rollback pin.

## Install for your user

```bash
agentrig plugin install codex agentrig/agentrig.core-committer --scope personal
```

AgentRig asks `codex app-server` to install and enable the plugin automatically.
Codex CLI `0.113.0` or newer is required. AgentRig does not edit
`~/.agents/plugins/marketplace.json` directly because that file is shared user
state.

To install without enabling immediately:

```bash
agentrig plugin install codex agentrig/agentrig.core-committer --scope personal --no-enable
```

## Workspace scope

Codex itself has no workspace-scoped plugin concept, so Codex plugin installs
reject `--scope workspace`. For workspace-scoped Codex skills, use
`agentrig skill install codex <skill> --scope workspace`.

## Uninstall Codex plugins

```bash
agentrig plugin uninstall codex agentrig/agentrig.core-committer
```

Uninstall is ledger-backed and hash-guarded:

- AgentRig delegates removal to Codex app-server
- install records include the concrete resolved version and registry snapshot digest

## What Codex plugins include

Codex exports can include:

- `skills/`
- `.mcp.json`
- `.app.json`
