# Codex integration

Install a resolved plugin into Codex:

```bash
agentrig plugin install codex agentrig/agentrig.core-committer
agentrig plugin install codex georg/georg.ts-master-plugin --scope workspace
```

`--scope auto` is the default selector.
For Codex, `auto` resolves to `workspace`.
Refs resolve to the latest installable registry version by default; add
`@<version>` only for an explicit reproducibility or rollback pin.

## Install for your user

```bash
agentrig plugin install codex agentrig/agentrig.core-committer --scope personal
```

With Codex `0.113.0` or newer, AgentRig asks `codex app-server` to install and
enable the plugin automatically. If Codex is missing or older, AgentRig writes
the plugin payload to the canonical Codex cache
(`~/.codex/plugins/cache/<marketplace>/<plugin>/<version>/`) and updates
`~/.agents/plugins/marketplace.json` so the plugin can still be enabled later
from Codex.

To install without enabling immediately:

```bash
agentrig plugin install codex agentrig/agentrig.core-committer --scope personal --no-enable
```

## Install for the current repo

```bash
agentrig plugin install codex agentrig/agentrig.core-committer --scope workspace
```

This writes a repo-local marketplace at `.agents/plugins/marketplace.json` and copies plugins into `./plugins/`.
When automatic Codex app-server install is available, AgentRig stages the local
marketplace in its persistent cache and Codex owns the enabled plugin state.

## Uninstall Codex plugins

```bash
agentrig plugin uninstall codex agentrig/agentrig.core-committer
```

Uninstall is ledger-backed and hash-guarded:

- AgentRig removes only files it previously installed
- modified plugin files are kept instead of being deleted
- unrelated marketplace entries are preserved
- existing extra metadata in `marketplace.json` is preserved when AgentRig updates its managed entry
- install records include the concrete resolved version and registry snapshot digest

## What Codex plugins include

Codex exports can include:

- `skills/`
- `.mcp.json`
- `.app.json`
