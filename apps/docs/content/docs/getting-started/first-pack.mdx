# Your first pack

This page is for pack authors.
If you want to consume packs from registries, start with [Getting started](/getting-started).

A pack is a folder with `meta.json` and the files you want to distribute.

## Scaffold the pack

```bash
agentrig pack init hello-skills
```

This creates a folder like:

```
hello-skills/
  meta.json
  skills/hello-skills/SKILL.md
  README.md
```

## Add files

Add skills, scripts, hooks, agents, or MCP config under the pack directory.
Then regenerate `meta.json`:

```bash
agentrig pack create . --out meta.json
```

## Test locally

Install your local pack from its `meta.json` as a provider plugin:

```bash
agentrig plugin install codex ./hello-skills/meta.json --yes
```

Next, learn about [`meta.json`](/packs/meta-json) and [`agentrig pack`](/cli/pack).
