# Your first plugin

This page is for plugin authors.
If you want to consume plugins from registries, start with [Getting started](/getting-started).

A plugin is a folder with `plugin.json` and the files you want to distribute.

## Scaffold the plugin

```bash
agentrig plugin init acme.hello-skills
```

This creates a folder like:

```text
acme.hello-skills/
  plugin.json
  skills/hello-skills/SKILL.md
  README.md
```

The scaffolded manifest uses the Agent Plugins shape:

```json
{
  "$schema": "https://agent-plugins.org/schemas/1.0.0/plugin.schema.json",
  "name": "acme.hello-skills",
  "version": "0.1.0",
  "description": "A reusable AgentRig plugin.",
  "author": { "name": "Your Name" },
  "license": "MIT",
  "keywords": [],
  "extensions": {
    "ai.agentrig": {
      "displayName": "Hello Skills",
      "kind": "plugin",
      "configSchema": { "type": "object", "additionalProperties": false, "properties": {} },
      "pluginDependencies": []
    }
  }
}
```

AgentRig plugin manifests are [Agent Plugins 1.0.0](https://agent-plugins.org/specification) conformant. AgentRig-specific fields live under `extensions["ai.agentrig"]`.

## Add files

Add skills, scripts, hooks, agents, or MCP config under the plugin directory.
The scaffold already creates `plugin.json`. Update it after you add your real files:

```bash
$EDITOR plugin.json
```

## Test locally

Keep author testing on the local export surface instead of the public install command:

```bash
cd ..
agentrig plugin export --agent codex --pluginsDir ./acme.hello-skills --out dist/codex-marketplace
```
