# Core concepts

Agentrig is built around a few simple primitives.

## Plugins

A plugin is a versioned bundle of files plus a `.plugin/plugin.json` install plan.
It can include skills, scripts, hooks, agents, MCP servers, or any file tree you want to distribute.

## Registries

Registries host plugin metadata and files.

- **Official registry**: `https://agentrig.ai/registry`
- **Community Plugins (hosted)**: plugins uploaded via `/submit`, published at `https://agentrig.ai/api/community`
- **Self-hosted registries**: registries you host yourself (static hosting works)

The **directory** (`https://agentrig.ai/directory/index.json`) is a curated list of registries for discovery and trust signals.

## Rigs

A rig is a named set of plugins. Rigs can extend other rigs, allowing team-wide baselines plus project-specific add-ons.

## Trust tiers

Agentrig classifies registries as:

- **Official** - `https://agentrig.ai/registry`.
- **Listed** - registries in the public directory index.
- **Unlisted** - any direct URL or unknown registry (requires `--yes`).

## Manifests

The CLI stores installed plugins in `.agentrig/manifest.json` so it can remove or update them safely later.
