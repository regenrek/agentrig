# Getting started

Agentrig helps you turn isolated AI habits into a shared way of working.
Instead of every person reinventing prompts, tools, and repo setup from scratch, you can keep what works, reuse it, and roll it out across projects.

## How it helps

- Get to useful AI help faster without rebuilding your setup in every repo.
- Spend less time repeating instructions, preferred tools, and team conventions.
- Start from proven workflows instead of trial and error.
- Carry the same working setup from project to project.
- Improve your setup once, then share it with everyone who needs it.

## How it can help your team

- Faster onboarding for new teammates.
- More consistent outputs across repos and contributors.
- An easier way to spread good practices without long setup docs.
- Shared defaults without forcing everyone into a rigid workflow.
- A cleaner path from "one person found something that works" to "the whole team can use it."

## Start small

You do not need to redesign your whole workflow on day one.
A common first step is to install agentrig, try one useful pack in one real repo, and keep only what helps.

## Try it

<Steps>
  <Step>
    <h3>Install agentrig</h3>
    <p>Make agentrig available in any repo so you can reuse the same setup wherever you work.</p>

    ```bash
    npm install -g agentrig
    # or
    pnpm add -g agentrig
    ```
  </Step>
  <Step>
    <h3>Connect to the official registry</h3>
    <p>Create the default config so agentrig knows where to pull shared packs from.</p>

    ```bash
    agentrig init --registry https://agentrig.ai/registry
    # or
    agentrig init --global --registry https://agentrig.ai/registry
    ```
  </Step>
  <Step>
    <h3>Add one useful pack</h3>
    <p>Start with a pack that solves a real problem for you instead of trying to model everything at once.</p>

    ```bash
    agentrig add core-committer
    ```
  </Step>
  <Step>
    <h3>Apply it (optional)</h3>
    <p>If the pack writes files into your repo, apply it and see the setup land in a real project.</p>

    ```bash
    agentrig rig apply
    ```
  </Step>
</Steps>
