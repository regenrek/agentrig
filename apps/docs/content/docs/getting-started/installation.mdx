# Installation

Agentrig is a TypeScript CLI that installs packs from registries.
Start with a global install for end-user usage, and use a repo install when you want it as a dev dependency.

## Requirements

- Node.js 18+ (recommended: latest LTS)
- pnpm 9+ (optional)

## Global install (recommended)

```bash
npm install -g agentrig
# or
pnpm add -g agentrig
```

## Install in a repo (dev dependency)

```bash
npm install -D agentrig
# or
pnpm add -D agentrig
```
