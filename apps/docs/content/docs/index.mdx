# Agentrig documentation

Agentrig helps devs and teams keep the AI workflows that actually work and reuse them across projects.
Instead of re-explaining tools, prompts, and conventions in every repo, you can package them once and roll them out where they matter.

<Callout title="What is a pack?">
A pack is a folder with `meta.json` plus the files you want to install (skills, scripts, hooks, agents, MCP, and more).
The CLI installs packs from the official registry, your team registries, or any direct URL.
</Callout>

## Works with the tools devs already use

Agentrig is not limited to one assistant or editor.
You can export and install the same pack as a native integration for the tools many developers already work in every day.

- [Claude Code](/integrations/claude-code): export packs as Claude plugins and install them through Claude's native marketplace commands.
- [Codex](/integrations/codex): export packs as local Codex plugins with personal or workspace installs, plus safe uninstall through the AgentRig ledger.
- [Cursor](/integrations/cursor): export packs as local Cursor plugins for personal installs or repo-local workspace installs.
- [Marketplace exports](/integrations/marketplace): configure multi-provider exports and generate provider-native plugin layouts for all supported integrations.

This matters because teams do not want to rebuild their workflows from scratch every time they switch tools.
With AgentRig, the same pack can stay portable across environments while still feeling native inside each integration.
