# Agentrig documentation

Agentrig helps devs and teams keep the AI workflows that actually work and reuse them across projects.
Instead of re-explaining tools, prompts, and conventions in every repo, you can package them once and roll them out where they matter.

<Callout title="What is a pack?">
A pack is a folder with `meta.json` plus the files you want to install (skills, scripts, hooks, agents, MCP, and more).
The CLI installs packs from the official registry, your team registries, or any direct URL.
</Callout>
