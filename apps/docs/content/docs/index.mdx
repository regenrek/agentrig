# Agentrig documentation

Agentrig helps devs and teams package the AI workflows that already work, then reuse them across projects, tools, and teams.
Instead of rebuilding the same setup for every repo or assistant, you can author it once as packs, compose it into rigs, and install it natively where people already work.

<Callout title="What is a pack?">
A pack is a folder with `meta.json` plus the files you want to install (skills, scripts, hooks, agents, MCP, and more).
The CLI installs packs from the official registry, your team registries, or any direct URL.
</Callout>

## Why teams use AgentRig

![How Agentrig standardizes and reuses AI workflows across projects and tools](/agentrig_explanation.jpg)

- **Reusable workflow packs:** package skills, MCP config, hooks, agents, commands, and rules into registry-installable packs that can be shared across projects.
- **Composable rigs for teams:** combine packs into shared setups for a stack, repo, or org so teams can standardize how they work with AI.
- **Native delivery where people work:** export the same workflows as integrations for [Claude Code](/integrations/claude-code), [Codex](/integrations/codex), and [Cursor](/integrations/cursor), with tracked installs and safer cleanup.

See [Marketplace exports](/integrations/marketplace) for provider-native output layouts and [Rigs](/rigs) for team composition.
