# Dependencies

Plugins can declare other plugins they depend on using `rigDependencies`.
Plugin installs resolve and install dependencies before the requested plugin.

```json
{
  "name": "core-committer",
  "rigDependencies": ["security-check"]
}
```

## How it works

- Dependencies can be official plugin names, `registryAlias/plugin` specs, or direct URLs.
- Dependencies inherit the same registry when a plugin is installed from a configured registry.
- Direct URL or local-file installs must use explicit dependency specs for any dependent plugins outside that source.
- Dependencies are only installed once per install run.

Use dependencies for shared foundations like linters, security checks, or base prompts.
