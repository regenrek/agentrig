# Plugin structure

Every plugin requires a root `plugin.json`. A README is recommended but not required.

AgentRig plugin manifests are [Agent Plugins 1.0.0](https://agent-plugins.org/specification) conformant. AgentRig-specific fields live under `extensions["ai.agentrig"]`.

## Common layout

```
plugin-name/
  plugin.json
  skills/
    <skill-name>/
      SKILL.md
      scripts/
  mcp.json
  ai.agentrig/
    scripts/
    agents/
    commands/
    hooks/
      hooks.json
    lsp.json
```

## Notes

- **skills/** and root **mcp.json** are the portable Agent Plugins v1 components.
- **ai.agentrig/** contains AgentRig-specific components such as commands, hooks, agents, rules, and LSP settings.
- Provider emitters translate AgentRig-specific components into each provider's native layout.

Use `agentrig plugin create` to scan a directory and generate a matching `plugin.json`.
