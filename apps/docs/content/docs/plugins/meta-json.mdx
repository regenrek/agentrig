# .plugin/plugin.json

`.plugin/plugin.json` defines a plugin's identity and metadata. It also powers
registry indexing and trust validation.

AgentRig plugin manifests are [Open Plugins 1.0.0](https://open-plugins.com/plugin-builders/specification) conformant. AgentRig-specific fields live under `x-agentrig`.

```json
{
  "$schema": "https://agentrig.ai/schema/plugin.v1.json",
  "name": "agentrig.core-committer",
  "version": "0.1.0",
  "description": "Adds a committer skill with a safe commit helper script.",
  "author": { "name": "AgentRig" },
  "license": "MIT",
  "keywords": ["git", "workflow"],
  "x-agentrig": {
    "displayName": "Committer Skill",
    "kind": "plugin",
    "configSchema": { "type": "object", "additionalProperties": false, "properties": {} },
    "pluginDependencies": []
  }
}
```

## Field reference

| Field | Required | Description |
| --- | --- | --- |
| `name` | Yes | Canonical Open Plugins machine identifier (`namespace.plugin`). |
| `version` | No | Semver version (`1.2.3`). |
| `description` | No | Short summary for registry listings. |
| `author` | No | Open Plugins author object, for example `{ "name": "AgentRig" }`. |
| `license` | No | SPDX identifier. |
| `keywords` | No | Open Plugins keywords for filtering. |
| `homepage`, `repository`, `logo` | No | Standard Open Plugins metadata. |
| `commands`, `agents`, `skills`, `rules`, `hooks`, `mcpServers`, `lspServers`, `outputStyles` | No | Standard Open Plugins metadata-only fields in this release. |
| `x-agentrig.displayName` | No | AgentRig display label. |
| `x-agentrig.kind` | No | AgentRig artifact kind, usually `plugin`. |
| `x-agentrig.configSchema` | No | AgentRig-specific plugin configuration schema. |
| `x-agentrig.pluginDependencies` | No | AgentRig plugin dependencies installed before this plugin. |

<Callout title="Schemas">
The CLI generates `$schema` using `https://agentrig.ai/schema/plugin.v1.json`.
</Callout>
