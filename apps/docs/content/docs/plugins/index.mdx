# Plugins overview

A plugin is a portable unit of workflow logic. Each plugin ships files plus a `.plugin/plugin.json` file that describes how to install them.

<Files>
  <Folder name="plugin-name" defaultOpen>
    <File name=".plugin/plugin.json" />

        <File name="SKILL.md" />
        <File name="commit.sh" />

    </Folder>
    <Folder name="scripts">
      <File name="lint.sh" />
    </Folder>
  </Folder>
</Files>

## What the CLI does

- Reads the plugin `.plugin/plugin.json`.
- Validates target paths and hashes.
- Writes files to the target directory (`{{skillsDir}}` by default).
- Records the install in `.agentrig/manifest.json`.
