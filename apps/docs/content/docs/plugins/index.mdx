# Plugins overview

A plugin is a self-contained Agent Plugins v1 package. Root `plugin.json`
declares identity and metadata; portable components are discovered from fixed
locations rather than from an AgentRig file-to-target map.

AgentRig plugin manifests are [Agent Plugins 1.0.0](https://agent-plugins.org/specification) conformant. AgentRig-specific fields live under `extensions["ai.agentrig"]`.

## What the CLI does

- Validates root `plugin.json`, package containment, `skills/*/SKILL.md`, and
  optional root `mcp.json` through `@agentrig/sdk`.
- Resolves plugin dependencies and AgentRig capability requirements.
- Emits Claude, Codex, or Cursor native layouts without changing the source
  package contract.
- Records exact source identity, resolved version, snapshot digest, generated
  paths, and owned hashes in `.agentrig/plugin-installs.json`.
