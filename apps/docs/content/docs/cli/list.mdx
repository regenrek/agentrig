# `agentrig list`

List AgentRig-managed full-plugin installs and artifact selections from the
personal and workspace ledgers.

```bash
agentrig list
```

## Options

- `--installed` - list installed plugins (default: true).
- `--cwd <path>` - working directory.

## Output

Installed plugins are read from the personal and workspace
`.agentrig/plugin-installs.json` ledgers. The output includes provider, effective
scope, exact resolved version, and external-repository provenance where
applicable.

Use [`agentrig search`](/cli/search) for marketplace discovery. The retained
`--available` flag prints that migration guidance and does not browse a local
registry index.
