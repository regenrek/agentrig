# `agentrig list`

List installed plugins (default) or available plugins in the registry catalog.

```bash
agentrig list
agentrig list --available
```

## Options

- `--installed` - list installed plugins (default: true).
- `--available` - list plugins available in the AgentRig registry catalog.
- `--registry <name|url>` - registry override.
- `--cwd <path>` - working directory.

## Output

Installed plugins are read from `.agentrig/manifest.json`.
Available plugins are fetched from `agentrig.ai` as catalog listing data.
