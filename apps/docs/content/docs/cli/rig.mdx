# `agentrig rig`

Rig commands operate on the `rigs` section of your config.

## List rigs

```bash
agentrig rig list
```

## Apply a rig

```bash
agentrig rig apply codex core
```

The provider is required and must be `claude`, `codex`, or `cursor`. The rig name
may be omitted when `defaultRig` is configured.

See the Rigs section for details on `extends`, `plugins`, scopes, and `--prune`.
