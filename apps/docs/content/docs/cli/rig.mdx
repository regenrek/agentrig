# `agentrig rig`

Rig commands operate on the `rigs` section of your config.

## List rigs

```bash
agentrig rig list
```

## Apply a rig

```bash
agentrig rig apply core
```

See the Rigs section for details on `extends`, `plugins`, and `--prune`.
