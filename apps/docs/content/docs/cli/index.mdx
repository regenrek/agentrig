# CLI overview

The CLI installs plugins, manages registries, and applies rigs.
Run `agentrig --help` for global help.

## Common commands

- `agentrig init` - create config file.
- `agentrig list --available` - browse available plugins.
- `agentrig view <plugin>` - inspect a plugin before installing.
- `agentrig plugin install <provider> <plugin>` - install a provider plugin.
- `agentrig plugin uninstall <provider> <plugin>` - remove a provider plugin.
- `agentrig rig apply <provider> <rig>` - apply an advanced rig.
- `agentrig registry add` - add a registry.
- `agentrig plugin init` - scaffold a new plugin.
