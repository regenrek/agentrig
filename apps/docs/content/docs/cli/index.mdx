# CLI overview

The CLI installs packs, manages registries, and applies rigs.
Run `agentrig --help` for global help.

## Common commands

- `agentrig init` - create config file.
- `agentrig add <pack>` - install a pack.
- `agentrig list` - list installed or available packs.
- `agentrig rig apply` - apply a rig.
- `agentrig registry add` - add a registry.
- `agentrig pack init` - scaffold a new pack.

Use the pages in this section for full options and examples.
