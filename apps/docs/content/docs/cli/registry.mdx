# `agentrig registry`

Manage the registries in your config file.

The official registry is seeded by `agentrig init`.
Third-party registries are explicit: add the registry first, then install plugins from it with `registryAlias/plugin-name`.

## List registries

```bash
agentrig registry list
```

## Add or update a registry

```bash
agentrig registry add georg https://georg.dev/agentrig
```

After adding a registry:

```bash
agentrig list --available --registry georg
agentrig plugin install codex georg/ts-master-plugin
```

Direct URLs and local files stay outside this listed path. Those installs are treated as unlisted and require `--yes`.

## Options

- `--cwd <path>` - working directory.
- `--global` - write to global config.

## Notes

- Registry aliases use lowercase letters, numbers, and hyphens.
- Registry URLs must point at a base URL that serves `registry.json` at the root.
- Use `--global` when you want a registry available across repos instead of only in the current project.
