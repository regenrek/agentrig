# `agentrig init`

Create a minimal `agentrig.config.json` or global config.

```bash
agentrig init
```

## Options

- `--cwd <path>` - working directory (defaults to current directory).
- `--registry <url>` - seeded primary registry URL (default: `https://agentrig.ai/registry`).
- `--global` - write to `~/.agentrig/config.json`.
- `--force` - overwrite existing config.

## What it writes

```json
{
  "$schema": "https://agentrig.ai/schema/config.json",
  "registries": [{ "name": "agentrig", "url": "https://agentrig.ai/registry" }]
}
```

`agentrig init` no longer writes default rigs or starter plugins.
It only seeds the registry-first config you need to start browsing and installing plugins.

## Next steps

After init, the CLI prints the recommended next commands:

```bash
agentrig list --available
agentrig view <registryAlias>/<namespace.plugin>
agentrig registry add <alias> <baseUrl>
agentrig plugin install <provider> <registryAlias>/<namespace.plugin>
```

Append `@<version>` to a registry ref only when you need an exact
reproducibility or rollback pin.
