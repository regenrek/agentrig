# `agentrig view`

Inspect a plugin's metadata and install plan without writing files.

```bash
agentrig view agentrig/agentrig.core-committer
agentrig view acme/acme.tauri-rust --json
```

Refs resolve to the latest installable registry version by default. Add
`@<version>` when you need to inspect an exact pinned version.

## Options

- `--cwd <path>` - working directory.
- `--json` - print structured JSON output.

The command also validates target paths and prints trust tier information.
