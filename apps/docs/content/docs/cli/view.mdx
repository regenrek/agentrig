# `agentrig view`

Inspect a plugin's metadata and install plan without writing files.

```bash
agentrig view agentrig/agentrig.core-committer@0.1.0
agentrig view acme/acme.tauri-rust@1.4.2 --json
```

## Options

- `--cwd <path>` - working directory.
- `--json` - print structured JSON output.

The command also validates target paths and prints trust tier information.
