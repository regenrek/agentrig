# `agentrig pack`

Pack utilities help you scaffold and export packs.

## init

```bash
agentrig pack init my-pack
```

Options: `--template`, `--dir`, `--title`, `--description`, `--author`, `--force`.

## create

```bash
agentrig pack create . --out meta.json
```

Scans a directory, hashes files, and writes `meta.json`.

## plugin export

```bash
agentrig pack plugin export --agent all --packsDir registry/packs --out dist/plugins
```

Exports each pack as a plugin for `claude`, `codex`, `cursor`, or `all`.

Options: `--agent`, `--packsDir`, `--out`, `--config`, `--marketplaceName`, `--ownerName`, `--ownerEmail`, `--pluginPrefix`, `--pack`, `--clean`.

## plugin install

```bash
agentrig pack plugin install --agent cursor --pack my-pack --scope workspace
```

Builds plugin output and installs it into the selected provider surfaces.
In interactive terminals, the CLI prompts for provider and pack selection.
In non-interactive runs, pass an explicit `--pack` or use `--all`.

`--scope auto` remains the default selector. For Cursor, `auto` still resolves to `personal`; use `--scope workspace` to install into the repo-local AgentRig convention at `.cursor/plugins/local/`.

Options: `--agent`, `--packsDir`, `--out`, `--config`, `--marketplaceName`, `--ownerName`, `--ownerEmail`, `--pluginPrefix`, `--pack`, `--scope`, `--force`, `--dryRun`, `--clean`.

## claude-marketplace

```bash
agentrig pack claude-marketplace --packsDir registry/packs --out dist/claude-marketplace
```

Compatibility alias for `agentrig pack plugin export --agent claude`.
