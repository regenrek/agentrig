# `agentrig pack`

`agentrig pack` is the author workflow.
Use it when you are creating or exporting local packs.

If you are consuming packs from registries, use the top-level commands instead:

```bash
agentrig list --available
agentrig view <pack-spec>
agentrig plugin install <provider> <pack-spec>
```

## init

```bash
agentrig pack init my-pack
```

Options: `--template`, `--dir`, `--title`, `--description`, `--author`, `--force`.

## create

```bash
agentrig pack create . --out meta.json
```

Scans a pack directory, hashes files, and writes `meta.json`.

## plugin export

```bash
agentrig pack plugin export --agent all --packsDir registry/packs --out dist/plugins
```

Exports local pack directories as provider-native plugin marketplaces for `claude`, `codex`, `cursor`, or `all`.

Options: `--agent`, `--packsDir`, `--out`, `--config`, `--marketplaceName`, `--ownerName`, `--ownerEmail`, `--pluginPrefix`, `--pack`, `--clean`.
