# Contribute

This section is for repo contributors and maintainers.
If you just want to use the CLI and install plugins, start with [Getting Started](/getting-started) instead.

## What you can do here

- Set up the monorepo and run the CLI via pnpm.
- Review catalog submissions and, when appropriate, start a verified-mirror PR.
- Add registries to the public directory.

## Where to start

- **Repo setup**: See the [setup guide](/contribute/setup) for cloning the repo and running the docs app + CLI.
- **Catalog and verified mirror**: Follow the [official registry workflow](/contribute/official-registry) to review listings and optionally mirror approved versions.
- **Production rollout**: Use the [production deployment runbook](/contribute/production-deployment) for the registry and website ordering.
