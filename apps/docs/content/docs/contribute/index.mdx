# Contribute

This section is for repo contributors and maintainers.
If you just want to use the CLI and install packs, start with [Getting Started](/getting-started) instead.

## What you can do here

- Set up the monorepo and run the CLI via pnpm.
- Add packs to the official registry and rebuild the registry output.
- Add registries to the public directory.

## Where to start

- **Repo setup**: See the [setup guide](/contribute/setup) for cloning the repo and running the docs app + CLI.
- **Official registry**: Follow the [official registry workflow](/contribute/official-registry) to add packs or directory entries.
