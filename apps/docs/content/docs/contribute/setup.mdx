# Repo setup

Use this guide if you want to contribute to the repo or run the official registry locally.

## Requirements

- Node.js 24 (matches repository CI)
- pnpm 11.1.1 (the version pinned by the workspace)

## Install dependencies

```bash
pnpm install
```

## Run the docs app

```bash
pnpm docs:dev
```

The docs app serves the docs site locally. The canonical official registry lives in the
separate `agentrig-registry` repo.

## Run the CLI in dev mode

```bash
pnpm dev:cli -- init --registry https://agentrig.ai/registry
pnpm dev:cli -- search review
pnpm dev:cli -- plugin install codex agentrig/agentrig.core-committer
```

<Callout title="Tip">
For end-user installs, use the global CLI workflow in [Getting Started](/getting-started) instead.
</Callout>
